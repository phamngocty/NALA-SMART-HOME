Cam Kết Kỹ Thuật: Bảo Toàn 100% Giao Diện Gốc

Để tuyệt đối không gây lỗi hay lệch bố cục hiện tại, màn hình chờ được thiết kế dưới dạng Lớp phủ độc lập (Transparent Overlay Object).

1.
Không đụng vào code cũ:

Giữ nguyên 100% hàm build_tab_devices(), build_tab_ai(), build_tab_intercom(), build_tab_settings() và thanh Header 38px.

2.
Chỉ thêm 1 Object duy nhất (`modal_screensaver`):

Kích thước 240×320, khi bình thường luôn mang cờ LV_OBJ_FLAG_HIDDEN (ẩn hoàn toàn, không tốn tài nguyên render CPU/RAM).

3.
Chạm là thức dậy tức thì:

Sự kiện chạm chỉ đơn giản là gán lại cờ LV_OBJ_FLAG_HIDDEN, trả lại màn hình làm việc đúng tab đang mở với độ trễ 0ms.

⚡ Thử Nghiệm Tương Tác

Độ sáng màn hình chờ:
40%

Mã Nguồn Bổ Sung Màn Hình Chờ (ESP32Time + LVGL 8)

Thêm vào cuối `ui_lvgl_dashboard.h` mà không làm thay đổi các hàm cũ

// 1. Khai báo thêm trong uiDashboard:
lv_obj_t* modal_screensaver = nullptr;
lv_obj_t* lbl_stb_time = nullptr;
lv_obj_t* lbl_stb_date = nullptr;
lv_obj_t* lbl_stb_clim = nullptr;

// 2. Hàm khởi tạo lớp phủ màn hình chờ (gọi 1 lần trong init):
void build_screensaver(lv_obj_t* scr) {
    modal_screensaver = lv_obj_create(scr);
    lv_obj_set_size(modal_screensaver, 240, 320);
    lv_obj_set_pos(modal_screensaver, 0, 0);
    lv_obj_set_style_bg_color(modal_screensaver, lv_color_hex(0x05070D), 0);
    lv_obj_set_style_border_width(modal_screensaver, 0, 0);
    lv_obj_set_style_pad_all(modal_screensaver, 4, 0);
    
    // Đặt cờ ẩn mặc định để không che màn hình gốc:
    lv_obj_add_flag(modal_screensaver, LV_OBJ_FLAG_HIDDEN);

    // Chạm vào là ẩn ngay màn hình chờ:
    lv_obj_add_event_cb(modal_screensaver, [](lv_event_t* e) {
        auto* ui = (UiLvglDashboard*)lv_event_get_user_data(e);
        ui->hide_screensaver();
    }, LV_EVENT_CLICKED, this);

    // Label giờ số to 32px
    lbl_stb_time = lv_label_create(modal_screensaver);
    lv_obj_set_style_text_color(lbl_stb_time, lv_color_hex(0xFFFFFF), 0);
    lv_obj_align(lbl_stb_time, LV_ALIGN_CENTER, 0, -25);

    // Label thứ ngày tháng
    lbl_stb_date = lv_label_create(modal_screensaver);
    lv_obj_set_style_text_color(lbl_stb_date, lv_color_hex(0x38BDF8), 0);
    lv_obj_align(lbl_stb_date, LV_ALIGN_CENTER, 0, 15);
}

// 3. Hai hàm bật/tắt an toàn:
void show_screensaver() {
    if (modal_screensaver) {
        lv_obj_clear_flag(modal_screensaver, LV_OBJ_FLAG_HIDDEN);
        lv_obj_move_foreground(modal_screensaver);
    }
}

void hide_screensaver() {
    if (modal_screensaver) {
        lv_obj_add_flag(modal_screensaver, LV_OBJ_FLAG_HIDDEN);
    }
}
